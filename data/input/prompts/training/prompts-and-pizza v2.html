// Database · Import & Export
Backup · Restore · Portable
Export saves your entire database — all saved component entries and your full prompt library — as a portable .json file downloaded to your Downloads folder. Filename includes the date so backups don't overwrite each other.

Import reads a previously exported file. You'll be asked whether to Merge (add imported data on top of what you have) or Replace (overwrite everything with the imported file).
